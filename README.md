## 📌 نبذة عن المشروع
«رواد المعمل» هو منصة تعليمية تفاعلية تحاكي مختبر الإلكترونيات والفيزياء لطلاب السنوات الأولى في كليات الهندسة والعلوم والمدارس التقنية. يهدف المشروع إلى معالجة الفجوة التعليمية الناتجة عن نقص المعامل والمعدات الفيزيائية، وتوفير بيئة تعلم قائمة على الاكتشاف والتعلم من الأخطاء بمساعدة الذكاء الاصطناعي، دون خوف من احتراق المكونات أو تلفها.

تركز النواة الأولى المعتمدة للمشروع على **تجربة قانون أوم وحماية الصمام الضوئي (LED)** بجهد مصدر $5\text{V DC}$ ومقاومة حماية $330\Omega$ وصمام بجهد أمامي $2\text{V}$، مع نمذجة فيزيائية دقيقة لجميع حالات التوصيل السليمة والخطرة.

## 🚀 التشغيل السريع (Quick Start)

المشروع مصمم بمعمارية **Zero Runtime Dependencies** (بدون أي تبعيات خارجية أو حزم إضافية في وقت التشغيل)، ويعمل فورياً داخل أي متصفح حديث يدعم معايير ES Modules و Native SVG.

### 1. تشغيل واجهة المختبر في المتصفح
**يشترط تشغيل خادم HTTP محلي** لتحميل وحدات ES Modules. لا تفتح `index.html` مباشرة عبر `file://`، فقد يمنع Firefox تحميل ملفات JavaScript المنفصلة.

```bash
# الخيار 1: باستخدام خادم Python المدمج
python3 -m http.server 3000 --bind 127.0.0.1
```
ثم افتح المتصفح على العنوان: `http://127.0.0.1:3000/`

### 2. تشغيل حزمة الاختبارات الآلية الشاملة
تعتمد الاختبارات بالكامل على محرك الاختبارات المدمج في بيئة Node.js الحديثة (`node --test`):

```bash
npm test
```
- **عدد الاختبارات المنفذة:** **94 اختباراً آلياً** (تشمل اختبارات توجيه الأسلاك `WIRE-001..007` واختبارات سلّم تلميحات المرشد `CONTRACT-005..010`).
- **النتيجة الحالية:** **94 ناجحاً، 0 فاشل، Exit Code: 0** في بيئة الإصلاح؛ فحص المتصفح الحي يحتاج قبولًا يدويًا على جهاز الفريق.
- تعتمد المدة على الجهاز وإصدار Node. تدعم اختبارات JavaScript الآن Node 22.16+ دون استيراد TypeScript في مشغل الاختبارات.

## ⚡ النواة العلمية ومحرك المحاكاة الحتمي (`src/domain/circuit/`)
المحرك مصمم كدالة نقية عديمة الحالة (Pure Function):
$$\text{simulate}(\text{snapshot: LabSnapshot}) \longrightarrow \text{SimulationResult}$$

### الحسابات الفيزيائية الصحيحة:
- تيار الدائرة: $I = \frac{V_s - V_f}{R} = \frac{5.0 - 2.0}{330.0} = 0.0090909\text{ A} \approx 9.09\text{ mA}$
- هبوط جهد المقاومة: $V_R = I \times R = 0.0090909 \times 330.0 = 3.00\text{ V}$
- هبوط جهد الصمام: $V_{LED} = 2.00\text{ V}$
- حالة الصمام: `ledOn: true` (مضيء) حصراً عندما تكون حالة الدائرة سليمة.

### كشف حالات الخطأ الخمس بدقة:
1. **عكس قطبية LED (`REVERSED_LED`):** تيار 0A والصمام مطفأ.
2. **غياب مقاومة الحماية (`MISSING_RESISTOR`):** حالة غير آمنة وحجب الأرقام فورياً كـ `null` ("غير محسوب").
3. **تجاوز المقاومة بسلك مباشر (`BYPASSED_RESISTOR`):** حالة خطرة وحجب القراءات.
4. **قصر المصدر المباشر (`SOURCE_SHORT`):** سلك يصل القطب الموجب بالسالب مباشرة، حجب الأرقام فورياً.
5. **الدائرة المفتوحة والمفتاح المفتوح (`OPEN_CIRCUIT` / `SWITCH_OPEN`):** تيار 0A والصمام مطفأ.

## 🎮 التفاعل الحركي وإدارة حالة المعمل (`src/features/lab/`)
- **تحريك القطع بالسحب (Drag & Drop):** تحويل إحداثيات اللمس والماوس بدقة عبر `svg.getScreenCTM().inverse()` مع تقييد الحركة داخل مساحة اللوحة (`10..670x` و `10..470y`).
- **تحديث مسارات الأسلاك آنياً (60fps):** تحديث منحنيات بيزييه أثناء السحب دون إعادة بناء DOM.
- **الحذف التسلسلي النظيف (Cascading Deletion):** حذف أي قطعة يؤدي تلقائياً إلى حذف كافة الأسلاك المتصلة بها دون ترك أسلاك يتيمة.
- **التراجع والإعادة المقيد (Undo/Redo):** تاريخ تراجع بسقف 40 خطوة لمنع تسريب الذاكرة، مع تصاعد حتمي للمراجعة (`revision++`) لحفظ توافقية المرشد الذكي.
- **التحكم بالكامل عبر لوحة المفاتيح:** تحريك القطع بالأسهم، حذف القطع بـ `Delete`، التراجع `Ctrl+Z`، وإلغاء التحديد بـ `Escape`.

## 🔎 إصلاحات الدقة العلمية قبل تسليم القائد (24 نوفمبر 2026)

- يستخدم `src/domain/circuit/solver-core.js` الآن **الرسم الكهربائي للعقد** ومسارًا واحدًا حقيقيًا يبدأ من موجب المصدر، ويعبر جميع المكونات، وينتهي بسالبه. تستورد واجهتا `solver.js` و`solver.ts` **التنفيذ المشترك نفسه** لمنع اختلاف نتائج JavaScript وTypeScript.
- تم إصلاح خطأين مؤثرين: عدم قبول أجزاء دوائر منفصلة على أنها حلقة سليمة، والكشف عن عكس LED في أي موضع من مسار السلسلة.
- لا تُعرض قراءات رقمية للحالات `unsafe` أو `unsupported`؛ تُعرض «غير محسوب» ورسالة تشخيصية بالعربية. حالة الدائرة المفتوحة تعرض تيارًا صفريًا، أما الجهد الذي لا يبرر النموذج حسابه فيبقى «غير محسوب».
- ترفض النواة الشبكات المتفرعة والمتعددة المصدر والمتعددة الحلقات، ولا تدعي محاكاتها. **النموذج تعليمي لدائرة واحدة، وليس محاكي SPICE عامًا.**
- **الاختبارات المسماة E2E-001…018 هي سيناريوهات Node.js للوحدات، لا اختبارات تشغيل متصفح حقيقي.** بقي `Browser QA = NOT RUN` في بيئة الإصلاح بسبب الحظر الإداري على المتصفح. يجب فتح الصفحات وتجربة الأسلاك، المفتاح، LED، والتجاوب في Firefox على جهاز الفريق قبل العرض المباشر.
- عند تشغيل الاختبارات في Node 22.16+ لا حاجة إلى `--experimental-strip-types` حاليًا، لأن مشغل الاختبارات يستورد نقاط دخول JavaScript؛ يستمر وجود ملفات TypeScript لمراجعة الأنواع.


## بدء التجربة من لوحة فارغة (G2.7)

- عند فتح المختبر لأول مرة لا تظهر أي مكونات أو أسلاك؛ **يبني الطالب الدائرة بنفسه** باستخدام قائمة الأدوات والتوصيل بين المنافذ.
- خيار **«الدائرة النموذجية»** يُحمّل دائرة المثال المكتملة **فقط** عند ضغط الطالب عليه، مع تأكيد قبل استبدال عمل موجود.
- خيار **«مسح الأسلاك»** يزيل التوصيلات فقط، بينما **«مسح الدائرة»** يزيل كل القطع والأسلاك ويعيد اللوحة فارغة بعد التأكيد. كلا الإجراءين قابل للتراجع.
- الانتقال بين صفحات التطبيق والعودة إلى المختبر يحافظ على العمل الحالي طوال الجلسة؛ لا يُعاد تحميل الدائرة النموذجية تلقائيًا.
- لا تُعرض قياسات رقمية عند خلو اللوحة من المكونات.


## رسم الأسلاك وسلّم تلميحات المرشد (26 نوفمبر 2026)

- **توجيه الأسلاك (`src/ui/wire-routing.js`):** يخرج كل سلك من جهة منفذه بزاوية قائمة، ويسير بمسار متعامد بزوايا مدوّرة يتجنب أجسام القطع ولا يتراكب مع الأسلاك الأخرى. بطارية المصدر تضع (+) على اليمين لتتجه الدائرة من اليسار إلى اليمين. لم يعد السلك يمر خلف القطعة، فلا يلتبس على الطالب أي طرف موصول.
- **المرشد:** أول تلميح لكل خطأ **سؤال توجيهي** لا يذكر الحل. إذا بقي الخطأ نفسه بعد عدة تعديلات على الدائرة (`EDITS_PER_LEVEL`) يصبح التلميح أدق، ثم يذكر الحل. حالات «الدائرة غير مكتملة» أكثر صبراً لأن بناء الدائرة يغيّر النسخة مع كل قطعة وسلك. يظهر تمييز بصري للقطعة المعنية من المستوى الثاني.
- **حد معروف:** يعدّ المرشد أي تعديل (حتى تحريك القطع) نسخة جديدة. لحساب أدق على قائد الفريق إضافة بصمة للتوصيلات في عقد الطلب.
