## 5. تسليم مرحلة G2: النواة العلمية والنموذج التفاعلي (Scientific Core & Interactive Demo)

> **تاريخ الإنجاز:** 24 نوفمبر 2026  
> **حالة البوابة:** `PASS` (مكتملة ومحققة بالكامل بكود خروج 0 وبإجماع الوكلاء المتخصصين)

### 1. ملخص الأعمال المنجزة في G2
1. **إدارة حالة المعمل النقية (Lab State Management):**
   - تطوير `src/features/lab/lab-state.ts` و `src/features/lab/lab-state.js` بنموذج حالة نقي وغير متناقض.
   - دعم التراجع والإعادة (Undo/Redo) المحدود بسقف `MAX_HISTORY = 40` خطوة لتفادي استهلاك الذاكرة.
   - الحفاظ على الثابت الصارم لـ Tutor Contract: زيادة رقم المراجعة تصاعدياً بشكل رتيب (`state.revision++`) عند التراجع أو الإعادة لمنع رمي `StaleRevisionError`.
2. **التفاعل الحركي وتحريك المكونات (Interactive Drag & Move):**
   - دعم تحريك المكونات بالسحب عبر المؤشر والشاشات اللمسية باستخدام `svg.getScreenCTM().inverse()` وتحويل إحداثيات CTM الصحيح.
   - تقييد إحداثيات الحركة داخل مساحة اللوحة (`10 <= x <= 670`, `10 <= y <= 470`) لمنع اختفاء المكونات خارج Canvas.
   - منع طوفان التراجع (Undo Flooding) عبر حصر تثبيت الخطوة في مكدس التراجع عند إفلات المؤشر (`pointerup` عبر `commitMove`) فقط في حال تغيرت الإحداثيات فعلياً.
3. **التحكم وحذف المكونات المتسلسل (Cascading Deletion):**
   - إضافة زر «حذف القطعة» إلى شريط Mission Control واختصار زر `Delete` / `Backspace` من لوحة المفاتيح.
   - حذف المكون يؤدي تلقائياً إلى مسح وحذف كافة الأسلاك المتصلة بمنافذه دون ترك أسلاك يتيمة (Orphaned Wires).
4. **التحكم باللوحة ولوحة المفاتيح (Keyboard Accessibility):**
   - دعم تحريك القطعة المحددة عبر أسهم لوحة المفاتيح (10px، و 30px مع Shift).
   - دعم التراجع `Ctrl+Z` والإعادة `Ctrl+Y` أو `Ctrl+Shift+Z`.
   - دعم إلغاء التحديد عبر زر `Escape`.
   - حذف السلك بالنقر المباشر عليه أو زر `Enter/Delete` عند التركيز عليه.
5. **الربط الحتمي بالمحرك الفيزيائي:**
   - استخراج لقطة نقية `toLabSnapshot(labState)` وتغذيتها لمحرك المحاكاة `simulate`.
   - ربط إضاءة الصمام وحالته البصرية بحالة المحاكاة الحتمية (`simulation.ledOn`).
   - كشف كافة حالات الخطأ الخمس بدقة: العكس `REVERSED_LED`، غياب المقاومة `MISSING_RESISTOR`، الدائرة المفتوحة `OPEN_CIRCUIT`، قصر المصدر `SOURCE_SHORT`، والتيار الزائد `OVERCURRENT`.

### 2. القرارات المعمارية الرئيسية (ADRs)
- **ADR-004: Monotonic Revision on State Traversal:** عند التراجع أو الإعادة، يتم استرجاع عناصر الدائرة وتوصيلاتها، مع زيادة `state.revision` رتيباً لحفظ توافقية مهايئ المرشد الذكي.
- **ADR-005: Inverse CTM Coordinate Normalization:** استخدام مصفوفة CTM العكسية لتحويل إحداثيات اللمس والماوس إلى فضاء SVG بغض النظر عن حجم الشاشة أو طي الشريط الجانبي.
- **ADR-006: Drag Commit on PointerUp:** فصل الحركة الآنية أثناء السحب (60fps DOM updates) عن تاريخ التراجع لمنع إغراق المكدس.

## Patch: independent scientific topology audit — 24 November 2026

After the G2.5 handoff draft, a new independent audit found two false positives: disconnected subcircuits and a reversed LED after a resistor. A single shared graph-aware solver (`solver-core.js`) now validates one real electrical path, detects polarity along it, rejects unsupported branching and suppresses all unsafe measurements. Both `solver.js` and `solver.ts` share that implementation. **75/74 Node unit/scenario tests pass**; the browser is administratively blocked in this environment, so visual/mobile QA remains **NOT RUN**. The new ZIP supersedes the older `dist/Rowad_AlMamal_G2.5_Handoff.zip`. Final team acceptance requires quick local Firefox checks. Tutor contract stays DRAFT.
