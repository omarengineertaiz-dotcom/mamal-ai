# رواد المعمل — تقرير الإصلاح المستقل قبل تسليم الفريق

**الإصدار:** G2.6 Scientific Correctness Patch — 24 نوفمبر 2026  
**المصدر:** ZIP الأصلي الذي قدمه صاحب المشروع، وليس إعادة كتابة التطبيق من البداية.  
**حالة الإصدار:** المحرك واختبارات Node جاهزة؛ **قبول المتصفح الفعلي ما زال مطلوبًا**.

## لماذا احتاج المشروع هذا التحديث؟

أظهر فحص مستقل أن المحرك السابق كان يقبل دائرتين منفصلتين على أنهما دائرة صحيحة، ويفشل في تشخيص LED المعكوس إذا وُضعت مقاومة بينه وبين مصدر الجهد. كانت هذه الأخطاء خارج تغطية الاختبارات السابقة (63 اختبارًا).

## الإصلاحات

1. **رسم كهربائي حقيقي:** يدمج `solver-core.js` المنافذ المربوطة بأسلاك في عقد كهربائية (Union-Find)، ويمشي مسارًا وحيدًا من موجب مصدر الجهد إلى سالبه عبر جميع الأجهزة اللازمة للحلقة. الاتصال الشكلي أو عدد الأسلاك وحده لم يعودا كافيين.
2. **قطبية LED:** تُستنتج من اتجاه المسار عبر المهبط/المصعد، مهما كان موضع المقاومة أو المفتاح في الحلقة.
3. **توصيلات خطرة أو خارج النطاق:** كشف قصر قطبي المصدر غير المباشر، تجاوز المقاومة عبر عقدة سلكية، ورفض التفرعات/المصادر الإضافية والشبكات غير المعروفة. غير المدعوم يظل غير محسوب بدل تخمين جهد أو تيار.
4. **سياسة قراءة متسقة:** كل قيم `unsafe` و`unsupported` تساوي `null`، وتظهر تحذيرات؛ يذكر تشخيص فرط التيار القيمة النظرية لأغراض التوعية دون اعتمادها كقراءة تشغيلية.
5. **عرض واجهة آمن:** حالة `unsupported` تظهر صراحة في `index.html` وتحجب القراءات وتطفئ LED.
6. **مصدر واحد للحسابات:** ملف JS مركزي، مع مدخل JS ومتصفح ومدخل TS مقيّد بالأنواع يشيران إلى التطبيق نفسه.
7. **الوثائق:** اعتماد HTTP المحلي بدل فتح `file://`، وتحويل الروابط المطلقة الخاصة بجهاز المطور إلى روابط نسبية قابلة للمشاركة، وتصحيح وصف اختبارات Node المسماة E2E.
8. **الصفحة التعريفية:** تصحيح وصف مسؤوليات قائد الفريق وزكريا لتطابق اتفاق الفريق.

## ما الذي يجب على قائد الفريق/صاحب المشروع اختباره؟

```bash
cd Rowad-AlMamal
python3 -m http.server 3000 --bind 127.0.0.1
```
ثم افتح `http://127.0.0.1:3000/` في Firefox. تأكد من الصفحات الخمس، القائمة الجانبية، التوافق على هاتف 360/390px، الدائرة النموذجية (~9.09mA, 3.0V)، فتح المفتاح، تبديل أسلاك LED عبر المقاومة لاختبار الخطأ، فك سلك من الدائرة، الحذف والتراجع والإعادة. تحقق من عدم وجود أخطاء Console (`F12`).
