# G2.7 — Student-first empty lab experience

## لماذا تغير السلوك؟
السلوك السابق كان يحمّل `loadDefaultModelCircuit(labState)` عند بدء التطبيق ومن زر بدء التجربة؛ وهذا يكشف الحل قبل محاولة الطالب.

## السلوك بعد الإصلاح
1. `createInitialLabState()` يعطي قطعًا وأسلاكًا فارغة، ولا تُستدعى دالة المثال عند بدء التطبيق أو الانتقال إلى المختبر.
2. تظهر رسالة تشجع الطالب على إضافة المكونات وبناء التوصيلات، والقيم الرقمية تكون شرطات لا قراءات محسوبة.
3. زر «الدائرة النموذجية» وحده يُظهر مثال التوصيل الصحيح، مع تأكيد إذا كان هناك عمل حالي.
4. زر «مسح الدائرة» يعيد اللوحة إلى حالة فارغة ويمكن التراجع عنه؛ «مسح الأسلاك» يحتفظ بوظيفته السابقة.
5. التنقل بين الصفحات يحتفظ بالحالة طوال الجلسة ويعيد إظهارها عند العودة.
6. الحفاظ على فصل محرك الحسابات العلمية عن منطق الواجهة.

## التحقق
تم تنفيذ `npm test` بنجاح: **81 اختبارًا ناجحًا، 0 إخفاق** (بما فيها 6 اختبارات جديدة). اجتاز المشروع أيضًا فحص TypeScript (`tsc --noEmit`) والتحقق من صحة تركيب وحدة JavaScript المضمنة. محاولة فحص المتصفح الحي توقفت بسبب سياسة الحاوية `ERR_BLOCKED_BY_ADMINISTRATOR`، لذلك تظل اختبارات النقر والتجاوب المرئية على المتصفح **NOT RUN** ويُطلب تأكيدها على جهاز المستخدم.

## حدود
لا يوجد حفظ مستمر للعمل بعد إغلاق/إعادة تحميل الصفحة؛ هذا خارج نطاق هذا الإصلاح.
